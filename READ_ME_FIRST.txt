PUBLICAR EN GITHUB PAGES
1. Descomprime este archivo. No subas el ZIP directamente.
2. Copia TODO el contenido de esta carpeta a la raíz de tu repositorio, conservando index.html, assets, downloads, fonts, images, model y .nojekyll. Para subir todos los archivos cómodamente, usa GitHub Desktop: abre el repositorio local, copia los archivos, pulsa Commit y después Push.
3. En GitHub, abre Settings → Pages. En Build and deployment selecciona Deploy from a branch, la rama main y /(root). Pulsa Save. Si tu rama tiene otro nombre, selecciona esa rama.
4. Cuando termine el despliegue, GitHub mostrará el enlace en Settings → Pages. Ábrelo y comprueba el idioma, el vídeo y una descarga antes de enviarlo.

Estos archivos ya están compilados: no necesitas Node, instalar dependencias ni contratar un servidor. Funcionan tanto en el dominio principal de GitHub Pages como dentro de la carpeta de un repositorio.

ENGLISH
Unzip this package and copy its complete contents into the repository root. Commit and push all files (GitHub Desktop is suitable). Under Settings → Pages, choose Deploy from a branch, your main branch and /(root), then Save. GitHub will display the published URL when deployment finishes. The site is prebuilt and supports repository subpaths.
